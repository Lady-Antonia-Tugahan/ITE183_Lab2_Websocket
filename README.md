# ITE183 Laboratory 2: WebSocket Server

A real-time multi-client chat application built with **Bonezegei Scripting Language (BSL) v1.3.3**, the Bonezegei `http` package, HTML, CSS, and browser JavaScript.

## Features

- HTTP server on port `8000`, serving `public/index.html` at `/`
- Custom page for unknown routes (`public/404.html`)
- WebSocket connection and disconnection logs with client IDs
- Welcome message to new clients using `server.send()`
- Message broadcasts to all active clients using `server.sendAll()`
- Chat interface with connection status, message log, and send form

## Requirements

- Bonezegei v1.3.3 (`bonezegei -v`)
- Bonezegei package manager (`bzg`)
- Browser such as Chrome, Safari, or Edge

**Platform note:** The lab documents Windows and Linux/GitHub Codespaces. For macOS, use the Linux-based GitHub Codespaces environment unless a compatible Bonezegei release is available.

## Run

In the project folder, run:

```sh
bonezegei -v
bzg install
bzg run
```

Open `http://localhost:8000/` in two browser windows. Enter a message in either window and click **Send**. Both should receive a message prefixed by `User <client-id> says:`. Open `http://localhost:8000/unknown` to view the custom 404 page.

**Codespaces:** The service listens on port 8000. Use the forwarded-port URL from the Codespaces **Ports** tab instead of your computer's `localhost`; set port visibility to **Private**. The client derives its WebSocket endpoint from the page address.

## Troubleshooting

- **`bonezegei` or `bzg` not found:** Install the course-required Bonezegei toolchain and reopen the terminal.
- **Cannot find `lib/http.bzg`:** Run `bzg install` from the project root.
- **Connection failed:** Check that `bzg run` is still active, and that the page is opened through the running server (not `file://`).
- **Port 8000 is busy:** Stop the other server process using port 8000 before retrying.
- **Codespaces WebSocket doesn't connect:** Check port 8000 is forwarded and use its browser-accessible HTTPS address; some server versions or forwarding configurations may require adjustment.
