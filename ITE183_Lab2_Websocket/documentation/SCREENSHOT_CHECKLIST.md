# Laboratory 2 Screenshot Checklist

Only add genuine screenshots from your own running project. Suggested filenames:

1. `01-bonezegei-version.png` — terminal shows `bonezegei -v` and v1.3.3.
2. `02-bzg-install.png` — terminal shows successful `bzg install`.
3. `03-server-running.png` — terminal running `bzg run` with connected client logs.
4. `04-multi-client-chat.png` — **two separate browser windows visible together**, showing the same message broadcast.
5. `05-custom-404.png` — visiting `/unknown` displays the custom 404 page.

For the report: describe what you did, what you observed, and whether any problems occurred. Never label a screenshot as successful if the test failed.
